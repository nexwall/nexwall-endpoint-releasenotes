# Nexwall Endpoint release notes

Source of the Nexwall Endpoint release-notes site (English, Spanish, Brazilian Portuguese), generated by `build.py`
(Python 3, no dependencies) and published with GitHub Pages on every push to `main`.

Layout and workflow follow the Nexwall Firewall release notes: `content/releases.json` (newest first),
`content/<version>/<lang>.json` (what is new in that version), `content/issues.json` (known and resolved issues, codes `NXE-xxxx`),
`content/compatibility.json` (tabs), `content/features.json`, `content/ui.json`, `content/site.json` (`docs_url`, `legal`).

Status values: `preview`, `rc`, `beta`, `stable`. The download page and the legal pages are switched off until the first
downloadable release and its terms exist (`content/site.json`).

```
python3 build.py
python3 -m http.server -d site 8000
```
